# CureBot — מערכת חיבורי וואטסאפ של CURE MINDSET

מערכת אחת, בקישור אחד, שמחברת כמה מספרי וואטסאפ שצריך — כמו Base44.
כל חיבור הוא מספר וואטסאפ אחד שהסוכן עונה בו בשיטת CureMindset.
חיבור בסריקת QR (כמו וואטסאפ-ווב). אין טוקנים, אין אימות עסקי, אין ספק ביניים.

## מי רואה מה
| | מה רואים | איך נכנסים |
|---|---|---|
| **קטי (מנהלת)** | כל החיבורים, יצירת חיבור חדש, קודים, מחיקה | הקישור הראשי + קוד המנהלת (`ADMIN_CODE`, או `PANEL_KEY` הקיים) |
| **משתמש/ת** | רק את החיבור שלו/ה: סריקה, סטטוס, הגדרות | קישור אישי `/u/<id>` + קוד בן 6 ספרות (או קישור כניסה ישיר) |

## חיבור חדש — 3 צעדים
1. קטי: **＋ חיבור חדש** ← שם + מספר להתראות ← מקבלת קישור + קוד (הקוד מוצג פעם אחת).
2. שולחת את הקישור למי שמחבר/ת את הוואטסאפ שלו/ה.
3. הוא/היא פותח/ת את הקישור במחשב, ומהטלפון: וואטסאפ ← מכשירים מקושרים ← קישור מכשיר ← סריקה.

## מה הסוכן עושה
- עונה אוטומטית לפניות פרטיות (לא בקבוצות, לא לסטטוסים, לא לערוצים).
- כברירת מחדל עונה **רק לפניות חדשות** — לא לאנשי קשר ששמורים בטלפון. אפשר לשנות במתג.
- **כשעונים בעצמנו לשיחה — הסוכן יוצא ממנה ל-12 שעות.** לא מתערב כשאדם אמיתי מדבר.
- במצוקה או כשמבקשים לדבר עם אדם — שולח התראה למספר ההתראות של החיבור.
- מבין הודעות קוליות (דורש קרדיט ב-OpenAI; בלי זה מבקש לכתוב).
- כל חיבור עם זיכרון ונתונים משלו — חיבורים לא מתערבבים.

## מצב התשובות
- **טקסטים (ברירת מחדל, חינמי):** מנוע מקומי בשיטת CureMindset. לא צריך מפתח.
- **OpenAI:** אם `OPENAI_API_KEY` עם קרדיט — המערכת עוברת לבד לתשובות זורמות.
  אם OpenAI מחזיר "אין קרדיט", המערכת חוזרת לטקסטים לחצי שעה ובודקת שוב (בלי לעכב תשובות).
  אין "OpenAI חינמי" ל-API.

## אבטחה ונגישות
- קודי גישה נשמרים רק כ-hash (scrypt). עוגיית כניסה חתומה (HMAC), HttpOnly, Secure, ‏30 יום.
- הגבלת ניסיונות: 8 כושלים ל-15 דקות לכל IP. הקוד מנוקה מהכתובת אחרי כניסה בקישור ישיר.
- משתמש/ת לא יכול/ה לגשת לחיבור של מישהו אחר (נבדק בשרת). הגנת CSRF (JSON בלבד), CSP עם nonce, X-Frame-Options.
- עברית RTL, תוויות לכל שדה, מתגים נגישים לקורא מסך, פוקוס בולט, ניגודיות AA, כבוד ל"הפחתת תנועה".

## הגדרות שרת (Render)
| משתנה | למה |
|---|---|
| `ADMIN_CODE` / `PANEL_KEY` | קוד המנהלת |
| `DATA_DIR` | תיקיית הנתונים (ברירת מחדל `/data` — הדיסק הקבוע) |
| `OWNER_NUMBER` | מספר ההתראות של החיבור הראשון שנוצר אוטומטית |
| `OPENAI_API_KEY` | אופציונלי — תשובות זורמות + תמלול קולי |
| `AI_MODE` | `texts` כדי לעבוד תמיד בטקסטים |
| `MAX_TENANTS` | מקסימום חיבורים (ברירת מחדל 6 — כל חיבור צורך זיכרון) |
| `BLOCKLIST` / `ALLOWLIST` | מספרים שלא עונים להם / שתמיד עונים להם |

⚠️ חיבור QR הוא שיטה לא-רשמית של וואטסאפ. וואטסאפ עלול להגביל מספר שפועל אוטומטית.
