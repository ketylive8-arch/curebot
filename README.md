# CureBot — סוכן מענה בוואטסאפ ל-CURE MINDSET

מתחבר לוואטסאפ בסריקת QR, בדיוק כמו וואטסאפ-ווב. אין טוקנים, אין אימות עסקי, אין ספק ביניים.

---

## שני סוכנים על מספר אחד

**מי שכותב אלייך** מקבל את CureBot — המענה של הקליניקה.
**את** מקבלת עוזר אישי. המערכת מזהה אותך לפי `OWNER_NUMBER` ומדברת איתך אחרת לגמרי.

### איך את מפעילה אותו
פתחי צ'אט עם עצמך בוואטסאפ ושלחי **הודעה קולית**. היא מתומללת ונענית.

פקודות מיידיות:

| מה שאת אומרת | מה שקורה |
|---|---|
| סטטוס | מצב הסוכן, כמה שיחות, כמה לידים |
| לידים | מי מחכה לך ומה כתבו |
| השהה | הסוכן מפסיק לענות לכולם |
| המשך | חוזר לפעול |
| שלח ל0501234567: הטקסט | שולח בשמך, והסוכן לא מתערב באותה שיחה 12 שעות |

כל דבר אחר שתגידי — שאלה, בקשה, מחשבה — נענה חופשי על ידי העוזר, עם נתוני הפעילות מול העיניים.

## מה זה עושה

- עונה אוטומטית לכל מי שכותב למספר המחובר
- מבין הודעות קוליות — מתמלל אותן בעברית ועונה
- זוכר את השיחה: 10 הודעות אחורה לכל פונה, מתאפס אחרי 48 שעות
- שולח כרטיס סיום עם האתר והקלנדלי בסוף כל שיחה, פעם אחת בלבד
- שולח לך התראה בוואטסאפ במצוקה או כשמבקשים לדבר איתך
- כשמבקשים אדם — משתתק באותה שיחה ל-12 שעות ומעביר אלייך
- לא עונה בקבוצות, לא לסטטוסים, ולא להודעות שאת שולחת

---

## מה צריך לפני שמתחילים

1. **חשבון Render** (או כל שרת שמריץ Node 20)
2. **מפתח Anthropic API** — מ-console.anthropic.com. שימי לב: מנוי Claude רגיל **לא** כולל גישת API, זה חיוב נפרד לפי שימוש
3. **מפתח OpenAI** — לתמלול ההודעות הקוליות בלבד. בלעדיו הכל עובד חוץ מקוליות
3. **סים לבוט** — מומלץ בחום שלא יהיה המספר האישי/עסקי הראשי שלך

## התקנה על Render

### שלב 1 — להעלות את הקוד ל-GitHub
צרי ריפו חדש והעלי אליו את התיקייה הזו.

### שלב 2 — ליצור את השירות
ב-Render: **New → Blueprint**, ולבחור את הריפו. הקובץ `render.yaml` כבר מגדיר הכל.

או ידנית: **New → Web Service**, Runtime: Node, Build: `npm install`, Start: `npm start`.

### שלב 3 — משתני סביבה
| משתנה | ערך |
|---|---|
| `ANTHROPIC_API_KEY` | המפתח שלך |
| `OWNER_NUMBER` | `972543032349` — לאן נשלחות ההתראות |
| `AUTH_DIR` | `/data/auth` |
| `PANEL_KEY` | סיסמה שתמציאי, מגנה על דף ה-QR |
| `MODEL` | `claude-sonnet-4-6` |
| `OPENAI_API_KEY` | לתמלול קוליות |
| `STT_MODEL` | `whisper-1` |

### שלב 4 — דיסק
חובה. Render → Disks → mount ב-`/data`, גודל 1GB.
בלי דיסק, כל הפעלה מחדש מוחקת את החיבור ותצטרכי לסרוק QR שוב.

### שלב 5 — סריקה
פתחי `https://<הכתובת-שלך>.onrender.com/?key=<PANEL_KEY>`.
יופיע QR. בנייד: **וואטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר** → לסרוק.

הדף יעבור למצב "מחובר". זהו.

## חשוב

**אל תשתמשי בתוכנית Free של Render.** שירות חינמי נכבה אחרי חוסר פעילות, והחיבור לוואטסאפ נופל בכל פעם. התוכנית Starter נדרשת כאן.

**סיכון חסימה.** חיבור QR הוא לא-רשמי ומנוגד לתנאי השימוש של וואטסאפ. מספרים נחסמים לפעמים. זה נכון לכל כלי מהסוג הזה — Base44, גרין-API, וגם זה. לכן: סים נפרד.
